# Farmview

O atual projeto tem como finalidade intregar um sistema web com aparelhos de baixo custo para cultivos em ambientes controlados

Esses aparelhos de baixos custos possui sensores como: Sensores de umidade do solo, umidade e temperatura do ar, aparelhos como câmeras, para monitoramento ao vivo
Ventoinha para refrigerção do ambiente e uma luz de led.
